# WITCH-DOS 1.0

Демка персонального сайта в стиле DOS для [@mentaIlyillgirl](https://x.com/mentaIlyillgirl).
Без фреймворков и сборки: один HTML, один CSS, один JS.

Это **отдельный демо-сайт на GitHub Pages**. Он не заменяет и не трогает
`home.br11k.dev` — тот домен остаётся как был.

Повод: [твит «он будет в стиле DOS — уж слишком это прикольно выглядит»](https://x.com/mentaIlyillgirl/status/2122875589614829829).

## Что внутри

- boot-последовательность WITCH-BIOS → WITCH-DOS;
- командная строка: `help`, `ls`, `cd`, `cast`, `brew`, `pet`, `oracle`, `neofetch`, `sudo`, `reboot` и другие;
- книга заклинаний с маной, d20 и зельями;
- гостевая книга (localStorage, без бэкенда);
- ASCII-фамильяр, который моргает и говорит;
- шар предсказаний;
- CRT-сканлайны, 88×31 кнопки, тикер и прочий 2000-й год;
- тёмная розово-фиолетовая палитра по мотивам аватарки.

## Локально

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Или просто открыть `index.html` файлом. Быстрый режим без загрузки: `index.html?noboot=1#magic`.

## Как персонализировать

| Что | Где |
| --- | --- |
| Имя, био, ссылки, записки, тексты | `index.html` |
| Список заклинаний, фразы кота, ответы шара, тексты консоли | `app.js` |
| Цвета и типографика | `:root` в `style.css` |
| Аватарка | заменить `favicon.svg` (пиксельная ведьма 16×16) или `<img>` в блоке `.avatar-frame` |

Вся вёрстка — обычные `section.page`, переключение по `data-page`. Добавить раздел:
секция + кнопка `data-page`, путь в `PAGES` и название в `PAGE_ALIASES` в `app.js`.

## Деплой на GitHub Pages

Репозиторий: `konovalov-nk/witch-dos` → https://konovalov-nk.github.io/witch-dos/

Pages включён из ветки `main`, каталог `/`. Файл `.nojekyll` уже на месте.
Никакого CNAME и кастомного домена: это самостоятельная демка.

```bash
git push origin main
```

## Демо-ограничения

- гостевая и счётчик зелий хранятся только в браузере;
- счётчик посетителей — театральный (база 41 + локальные визиты);
- «сервер» иногда перезагружается, но это часть шоу;
- звук по умолчанию выключен (PC-спикер включается кнопкой).
